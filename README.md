# expense-tracker

## 如何使用
1. 將`input_expenses.py`、`visualize_expenses.py`下載至同一資料夾
2. 將該資料夾開啟後，在cmd中開啟該資料夾
3. 在cmd輸入`python input_expenses.py`，進入用於輸入資料的程式
4. 根據cmd顯示的提示輸入資料
5. 結束資料的輸入後，在cmd輸入`python visualize_expenses.py`，開啟顯示資料的程式
6. 查看程式顯示的資料是否符合預期
